## Stretch

- #276: focus a new terminal session. After #275, which touches the same
  effects.
- #278: workspace selector focus. Close it if the packaged v3 build does not
  reproduce it.
- #283: contradictory run-profile status copy.
- #322: provider presets in the Add provider form, filling the API format and
  endpoint. After #306, so the presets are written against go-llm v0.3.0.
  Firn accepts two API formats today, `ollama` and `openai-compat`, so a
  provider that speaks neither is listed only by its OpenAI-compatible
  endpoint. A test checks every preset against the format list and the form's
  endpoint check.
- #373: move the Go toolchain past 1.25, which left security support when Go
  1.27 shipped. After #316, which declares macOS 14, so Go 1.27 (which
  requires macOS 13) is in reach: use go1.27.x. After #306 as well, since both
  edit `go.mod`. Go 1.27 also
  changes `encoding/json` behavior (see the issue), and golangci-lint moves in
  `lint.yml` and `.husky/pre-push` together if the pinned version cannot load
  the new toolchain.
- #376: run `govulncheck` in CI. After the v0.13.0 back-merge, which brings
  `develop` the `toolchain go1.25.14` line from #372; before it, the job would
  fail on the vulnerabilities #372 fixes. Scope, tool version and whether it
  gates pull requests are set out in the issue.

The criteria in [README.md](README.md), plus:

- A live smoke of the Golem panel after the go-llm bump, docked and undocked,
  against an Ollama and an openai-compat destination.
