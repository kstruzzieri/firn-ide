The release review (exit criterion 4) found two regressions against v0.13.0,
both from #415, and their fixes entered under the regression exception in PR
#440, merged into `release/v0.14.0` on 2026-10-13 at `b49166ec`:

- Opening a macOS or Linux folder whose name holds a backslash (`/tmp/a\b`)
  while its slash twin (`/tmp/a/b`) was open refreshed the open project
  instead of switching to the chosen folder. v0.13.0 compared the paths
  exactly.
- A restore waited for a fresh disk read of every expanded folder before
  reopening tabs, so one read that never answered (a hung network or FUSE
  mount) left the restore unfinished: tabs never reopened and no session save
  ran. v0.13.0 trusted the folders its saved snapshot had already painted.

## Known issues

Each ships in v0.14.0 as it did in v0.13.0, and each targets v0.15.0:

- #384: commit message generation sends the staged diff (up to 48 KiB) to the
  model without the deny rules Golem chat applies, so the content of a staged
  `.env`, key or credentials file can reach the prompt, and can leave the
  machine when the request goes to an approved remote destination on the agent
  route.
- #397: the run-profile store writes its profiles without checking whether
  `.firn/run-profiles.json` changed on disk, so a branch checkout or merge that
  rewrites the file is overwritten by the next Save, Pin, Adopt or Delete. The
  lost version can be recovered from Git.
- #396: closing the Save profile popover while a save is in flight drops its
  result, failures included, so the user may believe a failed save succeeded.
- #395: the Golem chat's live region reads the newest error in the whole
  transcript, so it can re-announce an earlier run's error after a later run
  answers, and it skips a repeated one.
- #429: Tab and Shift+Tab never leave a terminal session (both go to the
  shell; only Cmd shortcuts such as Cmd+Shift+P move focus out), its input does
  not name its session, and tabbing out of the session menu can drop focus to
  the page. #276 makes the first easier to reach.
- #355: the destination approval row names one model where the approval covers
  the whole endpoint, and hides the fallback path.
- #431: Golem's deny floor matches paths by name, so on Windows a trailing dot
  or space, an alternate data stream suffix or a short (8.3) name, and on any
  platform a hard link, can reach a denied file.
