## Known issues

Each ships in v0.13.0 as it did in v0.12.0:

- #361: New chat clears only the view, so the model still receives the cleared
  turns. A long session in one workspace can fail repeatedly at the 2 MiB
  session limit, and only a restart clears it. Target v0.14.0.
- #314: screen readers may not announce some Golem configuration status
  messages (the grant notice, the Refresh busy notice, the result of an Apply,
  the route editor's model match count). Target v0.14.0.
- #316: the declared macOS 12.0 floor is too low. The app uses web APIs that
  need Safari 15.4 (macOS 12.3), and its build targets Safari 16. Target
  v0.14.0.
- #355: the destination approval row names one model where the approval covers
  the whole endpoint, and hides the fallback path. Target v0.15.0.

## Exit criteria

The criteria in [README.md](README.md), with two notes:

- The VoiceOver pass and the packaged-app check pass when nothing regressed
