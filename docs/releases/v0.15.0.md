## Known issues

Each targets v0.16.0's Stretch list, and ships in v0.15.0 as it did in v0.14.0
unless its line says otherwise:

- #397: the run-profile store writes its profiles without checking whether
  `.firn/run-profiles.json` changed on disk, so a branch checkout or merge that
  rewrites the file is overwritten by the next Save, Pin, Adopt or Delete. The
  lost version can be recovered from Git.
- #396: closing the Save profile popover while a save is in flight drops its
  result, failures included, so the user may believe a failed save succeeded.
- #395: the Golem chat's live region reads the newest error in the whole
  transcript, so it can re-announce an earlier run's error after a later run
  answers, and it skips a repeated one.
- #429: Tab and Shift+Tab never leave a terminal session (both go to the
  shell; only Cmd shortcuts such as Cmd+Shift+P move focus out), its input does
  not name its session, and tabbing out of the session menu can drop focus to
  the page.
- #355: the destination approval row names one model where the approval covers
  the whole endpoint, and hides the fallback path. Targeting v0.16.0 since the
  amendment of 2026-10-24, where #491 (In) removes the hidden fallback path.
- #431: Golem's deny floor matches paths by name, so on Windows a trailing dot
  or space, an alternate data stream suffix or a short (8.3) name, and on any
  platform a hard link, can reach a denied file.
- #442: an unreadable run-recency sidecar is overwritten by the next run.
- #443: a failed older root read marks the root dirty and stops the
  restore's tree refresh early.
- #283: a run ended by quitting or by a workspace switch leaves its profile
  reading "just ran" on the card and "Never run" in the expanded panel.
- #342: while one route editor is open, a second editor on a route sharing its
  model can stage a change that undoes a Think mode or exposure the first just
  staged, without the first editor's Pending line naming it.
- #506: commit message generation refuses a model with no known context window
  that Golem chat accepts; the error names the cause and the setting. go-llm
  v0.3.0 and v0.5.0 read the same way, but v0.14.0 was not run to confirm it.
- #510: on macOS and Linux, Resolve on a conflicted `a\b/x.ts` while `a/b/x.ts`
  has unsaved edits writes those edits over the conflicted file and marks
  `a/b/x.ts` saved, so closing its tab loses them.
- #511: commit message generation fails in a repository whose folder name ends
  in a space. New in this release for generation (#384).
- #512: a route joining a shared model and declaring a different type for it can
  make an unchanged route on that model read Incompatible. New in this release
  (#311).
- #513: with a subfolder of a repository open, the Git panel says Golem's file
  access rules withheld a staged file that is only outside that folder. New in
  this release (#384).
- #515: keyboard focus falls to the page when commit message generation
  finishes, so a keyboard or VoiceOver user loses their place in Source Control.
  Read from the source at v0.14.0, which was not run to confirm it.
