The rules, exit criteria and release steps are in [README.md](README.md).
The milestone mirrors In and Stretch once this contract merges; the v0.15.0
items expected to roll stay in that milestone until its freeze.

**Theme:** one Golem model. A user picks the model Golem answers with in one
step, every commit message comes from that model and no other, and Apply asks
about a change only when the change can narrow what a use case receives. This
is the first slice of the Golem model discovery design as the issues #490 to
#503 record it, the slice that cites go-llm v0.5.0 APIs only.
