The rules, exit criteria and release steps are in [README.md](README.md).

**Theme:** one Golem model. A user picks the model Golem answers with in one
step, every Golem answer and every commit message comes from that model and
says so, and Apply asks about a change only when the change can narrow what a
use case receives. The theme is the first slice of the Golem model discovery
design (revision 8, approved 2026-10-30), the part that needs nothing new from
go-llm.
